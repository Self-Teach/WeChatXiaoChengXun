# WeChatXiaoChengXun

云南茶叶销售小程序示例代码。项目遵循微信小程序的基础语法与目录结构，不依赖云开发，所有数据均由本地 `data` 目录模拟。

## 功能概览
- **首页**：展示 12 款云南代表茶叶，可加入购物车，并提供快捷跳转至茶叶科普与个人中心。
- **茶叶科普**：整理普洱、滇红、月光白等茶类的介绍与冲泡建议，帮助用户了解茶文化。
- **购物车**：支持增减数量、删除商品、结算生成订单等操作，使用本地缓存存储。
- **个人中心**：管理登录信息、查看订单、维护收货地址，并快速进入购物车。
- **用户登录、订单中心、地址管理**：通过本地缓存持久化基础信息，符合电商小程序的基本流程。

## 使用说明
1. 将 `miniprogram` 目录导入到微信开发者工具，选择“无 AppID”或替换成自己的测试 AppID。
2. 编译后即可在开发者工具中预览首页、茶叶科普、购物车、个人中心等页面。
3. 所有静态数据与模拟订单、地址等信息均存储在本地 `Storage` 中，方便演示与二次开发。
