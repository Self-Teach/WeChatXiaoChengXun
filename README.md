# WeChatXiaoChengXun

基于微信小程序原生语法开发的“云茶汇”云南茶叶销售平台示例项目，采用本地数据模拟真实业务场景，不依赖云开发能力。

## 功能概览

- **首页**：八款云南核心茶品的精选展示，可查看详情并加入购物车。
- **科普**：云南茶分类、产地、存储、冲泡方法等图文知识折叠浏览。
- **购物车**：本地存储购物记录，支持数量调整、删除、清空与结算提示。
- **个人中心**：登录模拟、订单状态总览、地址管理、账号安全等模块。
- **详情页**：图文轮播、规格选择、购买数量调整、评价列表和分享按钮。

## 目录结构

```
├── app.js / app.json / app.wxss       # 全局入口与配置
├── data/                              # 本地“数据库”数据源
├── pages/
│   ├── index/                         # 商品精选页
│   ├── knowledge/                     # 茶叶科普页
│   ├── cart/                          # 购物车
│   └── profile/                       # 个人中心及其子页面
└── project.config.json                # 微信小程序项目配置
```

## 使用说明

1. 将项目导入微信开发者工具，选择“无 AppID”或体验号运行。
2. 确保开发者工具基础库版本 ≥ 2.27.0，以获得更佳的界面效果。
3. 所有业务数据均来自 `data/` 目录，可按需替换为真实接口或本地数据库。

> 本示例仅用于演示微信小程序前端实现方式，不包含后台服务。欢迎根据实际需求扩展支付、订单和用户体系功能。
